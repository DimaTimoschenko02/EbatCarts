## Контекст (кратко)

- Проект: клон SmashKarts.io. На Godot 4.6 готовы: браузерный мультиплеер (M0-M11), bicycle-физика v3.1. Застопорился из-за 4 проблем (автономность ИИ, тестирование геймплея, слабость ИИ в геймдеве, ассеты).
- 2026-07: research рынка → **вердикт: leaning migrate на браузерный JS/TS**. Главный аргумент — в браузере ИИ-агент может САМ тестировать игру (Playwright: клавиши + скриншоты + видео + JS-телеметрия). Детали: memory `project_migration_research.md`.
- Dima = PM (Node.js/TS разработчик, код не пишет). Claude = вся разработка. Бюджет тулов ≤$50/мес (по факту MVP ≈ $0).
- MVP: машинки ездят + стреляют + мультиплеер по ссылке. Не полный клон.
- Godot-код НЕ удаляем до Gate G1. Ветка миграции отдельная.

## Целевой стек

| Слой | Технология | Почему |
|---|---|---|
| Рендер/клиент | **three.js** (+ Vite, TypeScript) | Максимум примеров в обучении моделей → максимальная автономность ИИ. Без экспорта: код = браузерное приложение |
| Физика машинки | **Порт своей bicycle-модели GDScript→TS** (~490 LOC чистой математики) | Модель уже оттюнена и работает; физдвижок общего назначения не нужен |
| Мультиплеер | **Colyseus** (MIT, self-host, Node/TS) | Авторитарный сервер, state sync, комнаты из коробки. Заменяет «headless Godot subprocess на комнату» |
| Backend | **Существующий `server/`** (Express+SQLite): profiles, matches, db — остаются ~1:1 | Чистый Node, Godot-независим (~800 LOC). rooms.spawn/ws_proxy/healthcheck (~260 LOC) переделываются под Colyseus |
| Ассеты | **Kenney Racing Kit** (CC0, 110 моделей: машины+трасса) + уже имеющийся Space Kit; опц. Skybox AI ($20/мес), Meshy/Tripo для кастома | Бесплатно закрывает MVP |
| Тестирование | **Playwright / claude-in-chrome MCP**: управление клавишами, скриншоты, видео, чтение `window.__telemetry` | Ядро всей затеи — самотестирование агентом |
| Альтернатива-запаска | PlayCanvas (если Dima захочет визуальный редактор сцен) | Переезд внутри JS-мира дешёвый; решаем после slice |

### P0 — Проверка тестируемости («могу ли я вообще тестить») — ✅ DONE 2026-07-06 (гипотеза подтверждена)

**Гипотеза:** Claude может без человека: запустить браузерную 3D-игру → поуправлять машинкой → снять скриншоты/серию кадров → прочитать телеметрию (velocity/omega/позиция) → сделать осмысленный вывод о поведении (едет/дрифтит/застряла).

Задачи:
1. Мини-стенд `web-slice/`: three.js сцена — плоскость, машинка-бокс, простая аркадная физика, WASD.
2. Телеметрия: `window.__telemetry` (pos, speed, yaw, omega) + debug-API `window.__drive(throttle, steer, ms)` для детерминированных прогонов.
3. Локальный сервер (порт 8090), открыть в Chrome через claude-in-chrome.
4. Тест A: управление реальными key events. Тест B: прогон через `__drive` + чтение телеметрии. Тест C: серия скриншотов движения/поворота, оценка визуала.
5. Вердикт в этом файле + memory.

**Критерий выхода:** Claude предъявил Диме: скриншоты/гифку проезда + численную траекторию + свой вывод, сделанный ДО подсказок человека. Если управлять браузером/читать телеметрию не удалось после разумных попыток — фиксируем блокер, обсуждаем (возможно PlayCanvas/другой транспорт инпута, или остаёмся на Godot).

**Результат (2026-07-06):** ✅ Всё подтверждено. Claude сам: открыл стенд в Chrome, увидел сцену на скриншотах, прогнал детерминированный заезд (разгон 2с → поворот 2.5с → откат 1с) через `__runScript`, прочитал полную траекторию из `__trace`, сделал численный анализ (разгон совпал с аналитикой accel/drag; поворот = круг r≈9м при ω=2.2; lat до 3.8 м/с), проверил канал реальных key events (движение от нажатий W).

Найденные gotchas (уже решены в стенде, обязательны для P1):
1. **Топология двух ноутов:** сессия Claude Code на ноуте А (сервер), Chrome-расширение на ноуте Б → `localhost` не работает, открывать по LAN-IP (`http://192.168.0.101:8090`). Firewall python уже разрешён.
2. **Chrome rAF-троттлинг:** у перекрытого (occluded) окна rAF = 0 fps → физика на rAF замирает. Решение: физика на `setInterval` с substeps (PHYS_STEP=1/120) и catch-up по wall-clock; rAF только рендер.
3. **Скриптовые прогоны — в СИМ-времени**, не wall-clock → детерминизм при любом fps. Телеметрия сэмплится внутри физического цикла.
4. Удержания клавиш у claude-in-chrome `computer.key` нет (только press) → канал вождения для агента = script-API (`__runScript`) / synthetic events; press-канал подтверждён для smoke-тестов.

Стенд: `web-slice/` (three.js, `index.html`+`main.js`), сервер `py -m http.server 8090` из web-slice/.

### P1.5 — Map Editor (инструмент для Димы) — 🔄 MVP реализован (2026-07-06, коммит cfbffd8), ждёт клик-теста Димы

Решение: свой браузерный редактор поверх web-slice (та же кодовая база: рендер, ассеты, mapLoader, heightfield). Отвергнуты: Kenney Asset Forge (экспортит меш, не грид-JSON), Godot GridMap (нужен конвертер ориентаций, рендер отличается, умирает после миграции), Tiled/Blender (нет грида+высот в нужном виде).

MVP редактора (одна сессия):
1. Роут/страница `/editor` в web-slice (отдельный entry, общие модули).
2. Орбитальная камера (OrbitControls), грид-подсветка ячейки под курсором.
3. Палитра ассетов (все terrain-* + пропсы с превью), клик = поставить, ПКМ/Del = убрать.
4. Горячие клавиши: R — поворот 90°, Q/E или колесо — y_level, G — тумблер грид/пропс режима (пропсы — float-координаты).
5. Экспорт/импорт нашего map-JSON (кнопка + drag&drop файла), автосохранение в localStorage.
6. Индикация ловушек формата: side = HIGH y_level, ramp/sideCorner = LOW (подсказка в UI при выборе ассета, из map-building rules).
7. Тест-драйв: кнопка «Drive» — спавнит машинку с физикой прямо в редакторе (переиспользовать main.ts цикл).

**Критерий выхода:** Дима собрал/поправил карту мышкой без Claude и она играется в слайсе.

**Реализация (2026-07-06, два sonnet-агента параллельно, коммит `cfbffd8`):**
- `web-slice/editor.html` + `src/editor/main.ts` — страница http://192.168.0.101:8090/editor.html. Управление: СКМ-drag — орбита, колесо — зум, ЛКМ — поставить, ПКМ — удалить, R — поворот, Q/E — y_level (плоскость рейкаста двигается с уровнем), Esc — снять выбор. Ghost-превью, палитра по категориям (Terrain/Roads/Edges/Props), подсказки-ловушки для side (HIGH) vs ramp/sideCorner (LOW) в статус-баре. Export/Import JSON, автосейв в localStorage, кнопка Drive → игра открывается с картой из localStorage (`/?map=editor`).
- `src/game/sky.ts` — космическое небо (градиентный купол + 1200 звёзд, fog=false у материалов) — подключено в игру. Просьба Димы «серый фон не очень» закрыта.
